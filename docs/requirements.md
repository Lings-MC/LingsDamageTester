# DamageTester 需求清单

> 日期：2026-08-29 ｜ 项目：DamageTester（Bukkit 插件，Minecraft 26.2）

## 背景与目的

服主/管理员在测试武器、陷阱、环境伤害时，经常需要一个"打不死自己且能实时看到伤害数字"的模式。本插件提供可开关的**测试模式**：开启后自身受到任何伤害都不会死亡、血量自动回满，并在动作条实时显示每次受到的伤害数值。

## 功能点

### F1 进入/退出测试模式

- 根命令 `/damagetester`（别名 `/dt`），子命令（全小写）：
  - `on`：进入测试模式，提示成功；若已在测试模式，提示"已在测试模式中"。
  - `off`：退出测试模式，提示成功；若不在测试模式，提示"当前不在测试模式中"。
  - `toggle`：切换测试模式，按切换后状态提示。
  - `status`：查询当前是否处于测试模式。
  - `help`：帮助（格式对齐美学规范 §3§l 标题行）。
  - `reload`：重载配置文件（`show-cause`）。
- 无参数根命令输出运行横幅（ROOT_MESSAGE），未知子命令统一 `未知命令.` 文案。
- `on` / `off` / `toggle` / `status` / `reload` 需要 **Op** 权限（`PermissionUtils.nonAdminAuth`，对齐模板约定）；`help` 与横幅无需权限。

### F2 测试模式下显示自身受到的伤害数值

- 玩家处于测试模式时，每次自身触发 `EntityDamageEvent`，在**动作条**（不刷聊天栏）显示本次最终伤害。
- 文案格式：`<数值> 伤害 (来源)`；数值保留 1 位小数，按伤害大小着色：`< 2.0` 绿色 §a、`< 10.0` 黄色 §e、`≥ 10.0` 红色 §c；来源与说明文字用灰色 §7。
- 来源显示 `EntityDamageEvent.DamageCause` 的中文名（如 摔落/近战/岩浆），未收录的原因回退显示枚举名。
- 配置项 `show-cause`（默认 `true`）控制是否显示"来源"部分；`false` 时只显示数值。
- 只处理玩家自身受到的伤害；测试模式外的玩家完全不受影响。

### F3 测试模式下受到伤害后自动回到满血

- 每次受伤结算后的**下一 tick** 将玩家血量恢复至最大血量（读取 `Attribute.MAX_HEALTH`，不写死 20.0）。
- 若本次伤害为**致死伤害**（最终伤害 ≥ 当前血量），**取消**该伤害事件防止死亡，并同样恢复满血。
- 恢复只针对血量，不触碰饱和度、负面效果等其它状态。
- 玩家退出服务器时自动从测试模式集合中移除（不做跨重登持久化）。

## 成功标准（可验证）

1. `mvn clean package` 通过，`target/` 生成 `DamageTester-1.0.jar`，解压可见 plugin.yml 且 version 已被 Maven filter 展开。
2. `mvn test` 全部通过（TestModeManager、DamageMessageFormatter、DamageListener、QuitListener、命令子类）。
3. 部署到 Spigot/Paper 26.2 服务器：启动日志出现 `Enabling DamageTester` 且无堆栈。
4. 游戏内 `/dt on` 后：被生物攻击/摔落/着火/岩浆均不死亡，血量自动回满，动作条显示带颜色的伤害数值与来源。
5. `/dt off` 后：恢复普通受击行为（不再自动回血、不再显示伤害数值）。
6. 非 Op 玩家执行 `/dt on` 收到"你没有执行该命令的权限."。
7. 服务器重启/玩家退出后测试模式不残留（退出即清除）。

## 非目标（YAGNI）

- 不做文案/颜色的配置自定义（仅保留 `show-cause` 一项）。
- 不做测试模式跨重登持久化。
- 不做给其他玩家开关、查看他人状态、管理员远程管理。
- 不做伤害统计、历史记录、GUI 面板。
- 不支持 26.2 以下的服务端版本。
- 不处理 `/kill` 命令等极端数值的显示美化（显示原始数值）。

## v1.1 变更（2026-08-29）

### F4 测试日志（新增）

- 测试模式玩家每次受到伤害，写入 `plugins/LingsDamageTester/logs/damage-yyyy-MM-dd.log`（按日期分文件，UTF-8 追加）。
- 每行格式：`[HH:mm:ss] 来源 对 受害玩家 造成了 N.N 伤害（原因）`；`EntityDamageByEntityEvent` 取来源实体名，弹射物溯源到发射者（方块发射器记为「发射器」），无来源实体记为「环境」。
- 配置项 `damage-log`（默认 true）控制开关，`/dt reload` 即时生效；写日志失败仅记服务端警告，不影响测试。

### F2/F3 行为变更（受击体验统一）

- 读取到最终伤害后**统一取消伤害事件**（不再区分致死与否）：不真实扣血、不会死亡，修复旧版「致死伤害无受击音效」的体验割裂。
- 取消后由插件对受击玩家本人补播原版受击音效（`entity.player.hurt`），保证每次受击反馈一致。
- 回满血逻辑保留：每次受击后下一 tick 恢复满血（覆盖进入测试模式时已有血量缺失的场景）。
- 成功标准补充：`logs/` 下生成按日期命名的伤害日志且行格式正确；受击必有音效反馈。

## v1.2 变更（2026-08-29）

- 伤害监听优先级从 HIGHEST 调整为 **MONITOR**（仍 ignoreCancelled=true）：在其它插件（含 HIGHEST 处理者）完成伤害计算/修改之后读取最终伤害，再统一取消。MONITOR 上取消事件是本插件作为测试工具的既定职责（最后改写结果），vanilla 在全部分发结束后读取取消状态，行为正确。
